questa è la situazione attuale del programma. l'obbiettivo è creare un modello di ai al più basso consumo possibile che scansioni i file 3d (quindi bisogna reimplementare il "filtro" dei file caricati in solo file 3d, tipo .ply, .obj, .stl ecc) e i corrispettivi file di dati (quindi aggiungere un campo sia per il caricamento singolo che per ogni file caricato nel caricamento di folder per allegare un file .txt di informazioni, che potrebbero essere coordinate, profondità di scoperta, datazioni o dati ambientali) per trovare correlazioni tra i file dell'archivio. correlazioni non di tipo troppo specifico, cose come stessi pattern, stesso luogo di ritrovamento o dati fisici come spessore o texture. questo modello lavorerebbe su richiesta nella pagina research, in cui ci dovrebbero essere 3 opzioni, ricerca libera (su tutti gli elementi caricati), ricerca categorica (concentrata su una categoria) o ricerca specifica, selezionando un caricamento in particolare per cui cercare un match. naturalmente tutta la UI deve essere in inglese
